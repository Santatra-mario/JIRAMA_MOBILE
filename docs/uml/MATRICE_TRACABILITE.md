## Convention des diagrammes par cas

Pour chaque CUxx, trois fichiers distincts sont fournis :
- `DSYS_CUxx_*.puml` : séquence système (boîte noire), chapitre 5.4.4.
- `DSEQ_CUxx_*.puml` : séquence de conception (boîte blanche), chapitre 6.2.
- `DCL_CUxx_*.puml` : classes de conception par cas, chapitre 6.3.

Ces diagrammes sont des vues de conception. Lorsqu’un module JavaScript est représenté par une classe de contrôle, il s’agit d’une abstraction de conception et non de l’affirmation qu’une classe native existe dans le code.
